# Learning Workshop Drafts

This directory contains dated learning-workshop drafts generated from the corresponding release reports.

Drafts identify potentially useful concepts, prerequisites, terminology, examples, and learning objectives. They serve as input to the interactive Data Engineering Learning Coach.

These files are working artifacts for Agent coordination and processing. They are not authoritative learning material and may be challenged, expanded, simplified, skipped, or restructured during the human-in-the-loop learning session.

Only explicitly approved material is ultimately persisted under `learning/` and `review-cards/`.
