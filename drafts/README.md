# Learning Workshop Drafts

This directory contains dated learning-workshop drafts generated from the corresponding release reports.

Drafts identify potentially useful concepts, prerequisites, terminology, examples, and learning objectives. They serve as input to the interactive Data Engineering Learning Coach.

These files are working artifacts for Agent coordination and processing. They are not authoritative learning material and may be challenged, expanded, simplified, skipped, or restructured during the human-in-the-loop learning session.

Only explicitly approved material is ultimately persisted under `learning/` and `review-cards/`.

## Cross-workshop deduplication

Before generating or planning from a draft, read [`DEDUPLICATION.md`](DEDUPLICATION.md) and compare candidate learning objects with [`CONCEPT-REGISTRY.md`](CONCEPT-REGISTRY.md), relevant earlier drafts, and the finalized learning materials. Do not label a candidate **New** solely because its permanent topic file is empty. A new release or product example should normally update an existing concept's evidence/examples, not create a duplicate lesson or review card.

Classify each candidate as **New**, **Extension**, **Review**, or **Duplicate** using the policy. Update the concept registry whenever a new workshop draft is added. Keep workshop learning status only in the dated `workshop-progress/` records; the registry is a cross-date concept index, not a mastery or progress record. Historical drafts should remain unchanged unless explicitly requested.
